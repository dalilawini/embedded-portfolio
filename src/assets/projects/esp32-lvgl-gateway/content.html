GATEWAY ROLE

Turn wireless events into a local interface

This ESP32 gateway concept receives ESP-NOW sensor data and presents it on a touchscreen interface built with LVGL.

EVENT FLOW

Radio service to display service

  1. Receive sensor data over ESP-NOW.
  2. Pass the reading through a gateway service.
  3. Update the LVGL view with the latest state.

SYSTEM ARCHITECTURE

Sensor events to touchscreen interface

flowchart TD NODES[ESP-NOW Sensor Nodes] --> GATEWAY[ESP32 Gateway] GATEWAY --> DATA[SensorData] DATA --> DISPLAY[Display Manager] DISPLAY --> UI[LVGL UI] UI --> TOUCH[Touchscreen]

INTERFACE

Touchscreen presentation with LVGL

The gateway uses an ESP32 display platform with a touchscreen to make distributed sensor information available as a clear local interface.

ENGINEERING DECISION

Keep radio and UI work decoupled

Display rendering is separated from incoming radio events so the interface can remain responsive while new data is being received.
