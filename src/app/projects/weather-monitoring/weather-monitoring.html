Distributed environmental monitoring

The system separates environmental sensing from the local display, allowing sensor nodes to collect measurements while an ESP32 gateway presents the current state.

SENSOR NODE

Focused data acquisition

Each ESP8266 sensor node concentrates on reading its attached DHT sensor and communicating a clear payload, keeping sensing and interface concerns independent.

SYSTEM ARCHITECTURE

Acquisition, transport, presentation

  1. DHT sensor samples environmental data.
  2. An ESP8266 node packages a compact reading.
  3. ESP-NOW carries the reading to the ESP32 gateway.
  4. The gateway service updates the LVGL interface.

ARCHITECTURE

System architecture

WIRELESS LINK

ESP-NOW communication

ESP-NOW is used as the local wireless link between nodes and gateway. Keeping payloads explicit and small makes the communication boundary easy to inspect and extend.

GATEWAY SOFTWARE

Responsive display updates

The ESP32 gateway receives sensor events through a service layer, then updates the display without coupling radio handling directly to the visual presentation.

RESULT

Reusable embedded IoT pattern

The resulting architecture provides a repeatable starting point for distributed sensing: acquisition at the edge, a lightweight wireless transport, and a dedicated local interface.
